Bienvenue sur GitHub !

Qu'est-ce que Git ?

Git est un système de contrôle de version qui permet de suivre les modifications du code.

Qu'est-ce que GitHub ?

GitHub est une plateforme en ligne qui permet de stocker et de partager des projets avec Git.

Les commandes Git essentielles

  • git init : créer un dépôt
  • git add . : préparer les modifications
  • git commit : enregistrer les modifications
  • git push : envoyer le code sur GitHub
  • git pull : récupérer les modifications
